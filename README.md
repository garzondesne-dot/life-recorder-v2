# LifeRecorder v3.0.0

휴대전화 내장 마이크로 녹음하고, 무음 구간을 건너뛰며, 기록을 날짜별로 확인하는 Android 테스트 앱입니다. Capacitor 웹 화면과 네이티브 Java 녹음 서비스를 사용합니다.

## 사용

- 녹음 시작: 0.5초 길게 누르기. 정지: 1초 길게 누르기. 도중에 놓으면 취소합니다.
- 새 녹음은 자정 기준 00–02시, 02–04시 등 고정2시간 구간으로 병합합니다. 2시간은 시계상의 구간이며 무음 제거 후 재생 길이는 짧을 수 있습니다. 이전 구간 키 없는 녹음·외부 파일은 소급 병합하지 않습니다.
- 분석자료 내보내기: 짧게 누르면 하루 기록, 길게 누르면 오늘 자료 공유. 기본 음성9개+하루TXT1개씩 전달합니다. AI별 파일·길이·계정 제한은 별도이며 실제 첨부·전송은 받는 앱에서 확인합니다.
- 하루TXT에는 시각 대응과 분석 요청·개인 선호가 들어갑니다. 대화 전사문이 아닙니다. 현재 앱은 AI 분석 결과를 직접 생성하거나 받아 저장하지 않습니다.
- 첫 실행 사용 안내 후 권한·휴식·분석 선호·선택형 백업 가이드를 제공합니다. 설정에서 다시 볼 수 있습니다.

## Google Drive 자동 백업

설정에서 계정을 연결하면 저장 완료된 앱 소유 음성과 하루TXT를 `LifeRecorder/기기별/날짜별`로 보냅니다. 같은2시간 구간의 새 병합본은 같은Drive ID를 갱신합니다.

- 절약 모드 ON(기본): 무제한 네트워크(Wi-Fi 등)·배터리 여유 조건, 누락 확인1시간.
- OFF: 인터넷 연결 시 저장 완료 즉시 요청, 누락 확인15분.
- 지금 바로 백업: 현재 구간 마감 후 곧바로 이어 녹음하고, 절약 조건을 건너뛴 전송을 요청합니다. 모바일 데이터가 사용될 수 있습니다. Android 실행 제한과 오프라인을 무시하는 즉시 완료 보장은 아닙니다.
- 보관 기간 없음/2/7/15/30/60일은 로컬과 연결된Drive 백업에 공동 적용합니다. 만료 시 미백업 원본도 영구 삭제될 수 있습니다. 일반Drive 파일과 다른 기기 자료는 삭제하지 않습니다.
- 직접 수정·삭제를 양방향 전파하지 않습니다. 연결 해제 시 업로드와Drive 자동 삭제를 중단하고 기존백업은 남깁니다.

Google Cloud의 Drive API 및 Android OAuth 설정이 필요합니다. API 키·서비스 계정 JSON을 APK에 입력하지 않습니다. [설정 절차](docs/v2.4.6-drive-backup.md).

## 휴식과 재개

여러 요일·시간 구간을 설정할 수 있습니다. 정확한 알람 권한을 확인하세요. 미허용 시 재개가 지연될 수 있습니다.

기존 녹음 서비스가 살아 있으면 휴식 알람으로 재개합니다. 프로세스 종료 시 재개 확인 알림과 앱 화면 진입 후 복구 경로를 제공합니다. Android의 백그라운드 마이크 제한 때문에 강제 중지·재부팅을 포함한 모든 종료에서 자동 재개를 보장하지 않습니다. 재부팅 후에는 직접 시작합니다. 설정에서 예약·알람 수신·실제 입력 재개 기록을 확인할 수 있습니다.

## 설치·개발

기존 앱 ID `com.lifeblackbox.recorder`와 고정 테스트 서명을 유지하므로 기존 앱을 삭제하지 않고 업데이트합니다. 앱 삭제·데이터 초기화는 설정·내부 복구 기록·백업 영수증을 잃게 할 수 있습니다.

Node22 / Java21 / Capacitor8.5.3. `npm run check`, `npm test`, `npm run test:timeline`, `npm run test:publication`. Android 생성 후 `node scripts/patch-android.mjs` 및 `npx cap sync android`. GitHub Actions에서 단위 테스트·lint·APK·서명·반응형 화면·실제AAC 가상 기기 통합 검사를 수행합니다.

배터리 절감률·Google 실제 계정 연결과 전송·갤럭시 폴드7/8 야간 재개는 실기 확인이 필요합니다. 공개 배포용 서명·스토어 준비는 별도입니다.
