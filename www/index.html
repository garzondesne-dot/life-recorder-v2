연결 설정 도움말
연결 오류가 나면 Google Cloud에서 Drive API를 사용 설정하고 Android OAuth 클라이언트에 앱 패키지명과 서명 SHA-1을 등록해야 합니다. API 키나 서비스 계정 JSON을 앱에 입력하지 않습니다.
저장 공간
오늘을 포함한 보관 일수입니다. 켜면 미전송 녹음도 삭제됩니다. 해당 음성의 타임로그와 연결된 Drive 백업도 영구 삭제합니다. 최근 공유 준비 자료는 최대 하루 동안 보호합니다. 외부 폴더는 제외합니다.
