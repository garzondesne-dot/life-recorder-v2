# LifeRecorder v3.0.0

기준 v2.4.6 (918cd6cc). 앱 ID `com.lifeblackbox.recorder`와 기존 고정 서명·설정·녹음 경로 유지. versionCode13. main 직접 커밋/병합 없음.

## 조작·이름
- 홈·런처·녹음 알림·타임로그·프롬프트의 앱명을 LifeRecorder로 통일한다. 설치 ID·서명은 바꾸지 않는다.
- 시작은 0.5초, 정지는 1초 길게 누르기. 같은 원형 진행선이 차오르고 중도 이탈/취소/화면 숨김/페이지 이동/녹음 상태 변경 시 취소한다. 짧은 터치로는 시작하지 않는다.
- 키보드·보조기술의 클릭은 명시적 확인 후 시작/정지하여 긴 누르기 불가능한 사용자도 조작할 수 있다.

## 첫 실행 가이드
- 사용 안내 확인 → 앱 소개 → 선택형 권한 안내 → 반복 휴식 → 개인 분석 선호 → 선택형 Drive 백업 → 실제 녹음 없는 길게 누르기 연습.
- 새 설치/기존 사용자 모두 아직 확인하지 않은 사용 안내는 확인해야 한다. 확인 후 나머지 가이드는 나중에 할 수 있다. 기존 설정/기록은 보존하며 설정에서 다시 볼 수 있다.
- 마이크·알림·배터리·정확 알람은 각 버튼을 눌렀을 때만 권한 또는 기기 설정을 연다. 가이드를 열었다고 녹음·Google 로그인·업로드하지 않는다.
- 분석 항목 복수 선택/순서, 추가 요청, 답변 분량(짧게/핵심+근거/상세)을 하루 기록의 같은 선호와 공유한다.

## 프롬프트·TXT
- 저장한 우선순위·답변 분량·추가 요청과 사실/해석/확인 원칙을 공용 하루 TXT에 포함한다. 텍스트를 대화 전사문으로 오인하지 않도록 명시한다.
- 공유 시 현재 묶음의 실제 프롬프트를 고정 TXT 사본 앞부분에 함께 넣는다. 별도 파일로 늘리지 않고 음성 최대9개+하루TXT1개를 유지한다.
- 공유할 때마다 이전에 전달한 사본을 덮어쓰지 않는다. 공용 날짜 폴더의 TXT는 계속 하루1개이며, 공유용 고정 사본은 앱 내부 캐시로24시간 보호/정리한다.
- 이름·화자·담당자·기한·누락은 확인 질문, 기간 보고는 실제 제공된 자료만 사용하도록 지시한다. 플러그인 자동 실행·장기 기억·To-do 앱 등록·AI 결과 회신은 구현하지 않았으며 완료했다고 주장하지 않는다.
- 현재 앱은 직접 AI 분석하지 않는다. 외부 AI의 파일 지원/지침 준수/정확도는 별도다.

## Drive 절약 모드
- 기본 ON. 자동 음성·TXT 업로드는 UNMETERED(일반적으로 Wi-Fi) + Android BatteryNotLow 조건으로 대기한다. 누락 보완은1시간 주기.
- OFF는 인터넷 연결 조건으로 저장 완료 즉시 작업을 요청하며 누락 확인15분. 미완성 저널의 스트리밍은 아니다.
- 지금 바로 백업은 현재 구간을 안전하게 마감하고 마이크를 유지하며 새 파일에서 이어 녹음한 후, 절약 조건을 건너뛴 한 번의 작업을 요청한다. 모바일 데이터/배터리 사용에 명시적으로 확인한다. 네트워크 없음·Android 스케줄러 지연·오류까지 무시하지는 않는다.
- 수동 백업의 파일 확정은 기존 오디오 스레드의 저장 장벽을 사용하되 AI 공유 스냅샷/전송 확인을 생성하지 않는다.
- 보관 만료 Drive 삭제는 별도 인터넷 연결 작업으로 요청하여 Wi-Fi/낮은 배터리를 기다리느라 삭제까지 보류되지 않게 한다. 녹음은 백업 배터리 조건과 무관하다.
- 나머지 v2.4.6의 계정별 영수증·같은ID 갱신·중단 재개·만료 파일 전송 금지·소유 표식 확인·삭제 보류·연결 해제 동작은 유지한다.
- 보관 기간이 지나면 미백업 원본도 지워질 수 있다. 백업을 기다린다는 이유로 보관 기간을 연장하지 않는다.

## 예약 재개 보강과 제한
- 기존은 프로세스에 동적으로 등록한 알람 수신기만 있었다. 프로세스가 없어지면 해당 수신기로 재개할 수 없다. 사용자 스크린샷만으로 OS 종료/알람 지연/입력 오류 중 실제 원인을 확정하지 않는다.
- 명시적 Manifest 수신기, 현재 사용자 녹음 의도·기기 부팅 식별·설정·예약/알람 수신/실제 입력 재개 시각을 보존한다. 수동 정지한 세션이나 오래된 알람으로 재시작하지 않는다.
- 기존 마이크 FGS가 살아 있으면 알람이 웨이크락을 재획득하고 휴식 대기를 깨워 실제 입력 확인 후 재개 기록/알림을 갱신한다.
- 프로세스가 사라졌으면 마이크 FGS를 백그라운드에서 몰래 새로 시작하지 않는다. 재개 확인 알림을 표시하며 같은 부팅의 휴식 종료가 확인된 경우 앱이 화면에 보일 때 이전 사용자 녹음 의도로 재개를 시도한다.
- Android14+ while-in-use 마이크 제한, 강제 중지·재부팅·배터리 정책 때문에 모든 종료 상황에서 무조건 자동 재개를 보장하지 않는다. 재부팅 후에는 직접 시작한다.
- 정확한 알람 허용 상태/설정 버튼과 예약 진단을 설정에 표시한다. 미허용 시 일반 알람으로 대체하고 지연 가능성을 표시한다.
- 폴드7/8의 밤새 화면 꺼짐 및 실제7시 재개는 실기 확인이 필요하다.
