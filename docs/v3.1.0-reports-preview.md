# LifeRecorder 3.1.0 — 보고서 미리보기

v3.0.0의 녹음 엔진·병합·휴식·Drive 백업·서명은 유지하고, 외부 AI 결과를 앱 안에서 검토하고 보관하는 첫 단계를 추가합니다.

## 사용할 수 있는 기능

- 홈의 **보고서 보기**, 하루 기록의 **이 날짜 보고서 보기**, 설정에서 진입합니다.
- 날짜별 보고서가 있으면 최신 내용을 엽니다. **저장 버전**으로 과거 결과를 볼 수 있습니다. 재분석 결과를 가져와도 원문과 이전 후보 선택은 남습니다.
- **샘플 보기**는 가상 데이터이며 저장되지 않습니다. **저장 기록 보기**로 실제 보관함으로 돌아옵니다.
- **이 날짜 분석 자료 준비**는 기존 외부 AI 공유 화면을 엽니다. 현재 우선순위와 JSON 반환 형식을 프롬프트에 포함합니다. 파일을 AI 앱에서 실제 전송하고, 답변을 복사해 **결과 붙여넣기 → 새 버전 저장**하세요. 실제 음성을 앱이 자동 분석하거나 무료 Gemini API에 보내지 않습니다.
- JSON에는 summary(1~3개), sections(topic/text/evidence), todos(title/assignee/due/evidence), speakers(label/name/relation/note), coverage를 쓸 수 있습니다. topic은 todo/speech/brief/relation/memory/emotion입니다. due는 YYYY-MM-DD 또는 빈 문자열입니다.
- 일반 텍스트도 가져올 수 있습니다. 첫 3줄(각 최대 2,000자)을 요약으로, 전체 글(최대 30,000자)을 본문으로 저장합니다. 일반 텍스트에서 할 일·화자를 자동 추출하지 않습니다. 앱은 외부 결과를 원본과 대조하지 않았다고 표시합니다.
- 선택한 분석 항목이 외부 결과에 없으면 **분석이 없음**을 표시합니다. 가져온 시점의 우선순위를 함께 보관하며 원래 AI가 따랐다고 보증하지 않습니다.
- 할 일 후보의 제목·담당자·기한·선택을 저장하고 선택 항목을 복사합니다. 선택은 완료·Tasks 등록이 아닙니다. Google Tasks 직접 연동은 미구현입니다.
- 화자 A/B와 인물을 자동 병합하지 않습니다. 기존 인물을 사용자가 연결하거나 새 이름을 확인합니다. 확정 인물의 이름·관계·사용자 메모를 따로 조회·수정·삭제합니다. 이름이 같아도 별도 인물로 유지합니다.
- 확인한 인물 정보는 별도의 **요청에 포함** 선택을 켰을 때만 새 분석 요청에 들어갑니다. 기존 외부 AI 공유 프롬프트에는 자동 노출하지 않습니다.

## 보관과 계정

Android 내부 files/reports-v1에 AtomicFile로 저장합니다. 백그라운드 작업·네트워크·오디오 읽기·새 권한을 추가하지 않습니다. Google Drive 연결 계정 ID를 해시해 보관함을 나누며, 연결 전/해제 상태에는 별도 기기 보관함을 사용합니다. 계정 변경 중 진행되던 오래된 보관함 요청은 거부합니다. 기존 로컬 보고서를 새 계정에 자동 이전하지 않습니다. 이 분리는 같은 앱을 잠금 없이 사용하는 사람에 대한 별도 접근 잠금 기능이 아닙니다.

보고서와 인물은 음성 자동 정리 대상이 아닙니다. 사용자가 날짜 전체 보고서 또는 인물을 명시적으로 삭제합니다. **Drive 보고서 백업은 아직 없습니다.** 앱 삭제·데이터 초기화 시 내부 기록도 삭제됩니다. 원래 AI 화자 표기는 원문으로 남고 사용자 확인 연결은 별도로 저장합니다. 인물 삭제 시 확인 연결이 해제됩니다.

## 다음 단계

실제 Gemini API 분석(개인정보 처리 조건과 비용 방식 확정 후), Google Tasks 등록, 보고서 Drive 백업, 서버 예약·주간·월간 분석은 다음 단계입니다. API 키 입력·유료 전환·서버 배포는 하지 않습니다. 예약 요구는 일요일 22시·매월 말일 22시까지의 자료이며 이후 자동 보충하지 않는 것으로 유지합니다.

## 검증

JavaScript 구문·기존 녹음/내보내기 회귀, 보고서의 샘플 격리·HTML 이스케이프·입력 검증·인물 정보 명시적 포함 테스트를 실행합니다. Android에서는 원문 버전/선택 보존, 계정 격리와 오래된 요청 차단, 같은 이름 자동 병합 금지, 삭제 연결 해제, AtomicFile 복구, 원본 음성 비삭제를 테스트합니다. 기존 실제 AAC 녹음 병합·해석·동결 공유 통합 테스트를 유지합니다.
